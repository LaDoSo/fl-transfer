FL Transfer 1.2.0 User Guide
============================

Moves the samples, instruments and Patterns of one FL Studio project into another project
that is open in FL.
A Pattern takes every instrument it uses with it, and the instruments keep their settings.
Samples can be auditioned in the window before you decide which one to move.


1. What you need
----------------
- Windows 10 / 11, 64-bit. Python or anything else does not have to be installed.
- FL Studio. The tool was tested with FL Studio 2025 (25.2.5); other versions were not tested.
- The plugins used by the source project (Serum, Keyscape and so on) must be installed on
  this computer, otherwise FL cannot load the instruments.


2. How to use it
----------------
1. Start FL Transfer:
   - Installer: run "FL-Transfer-Setup-1.2.0-en.exe", then open "FL Transfer" from the
     Start menu or the desktop. It is installed for the current user only and needs no
     administrator rights.
   - Portable: unpack the whole archive anywhere and double-click "FL Transfer.exe" inside.
     (Keep the whole folder together; do not take the exe out on its own.)
2. In FL Studio, open the "target project", the one you want to add things to. The target
   project must have been saved (it must have a file name).
3. Under "Source project" at the top of the FL Transfer window, choose the .flp to take
   things from (the drop-down lists the projects FL opened recently; you can also click
   "Browse…", or drop a .flp onto the window).
   To find a sample, type part of its file name or channel name into "Search samples". The
   number of matches and the total number of samples are shown on the right.
   Esc in the search box, or "Clear", shows all samples again. Samples that are filtered
   out are deselected automatically.
4. The upper part of the window holds the Patterns, the lower part the samples and
   instruments. There are three ways to move a card into FL, all with the same result:
   - drag the card onto the FL window and release it;
   - double-click the card (for a sample card, double-click its title bar; a click on the
     waveform auditions it, see section 3);
   - click to select it (Ctrl / Shift selects several), then click "Send to FL".
5. When a Pattern is sent:
   - The tool first has FL save the target project once (the same as pressing Ctrl+S for
     you). The first time, it asks whether you agree.
     This step cannot be skipped: the notes have to say which channel they belong to, and
     that number can only be read from the saved file.
   - FL then loads the instruments; the new channels appear at the bottom of the Channel Rack.
   - When loading has finished, FL switches to the new Pattern by itself; the notes are in
     the rows of the new instruments.
   - The status bar at the bottom of the window says which number the new Pattern has.


3. Auditioning samples
----------------------
- Click the waveform of a sample card: playback starts from that position. Click another
  position while it plays and it jumps there and carries on.
- Click the small triangle at the left end of a sample card's title bar: plays from the
  start; click again to stop.
- Select one sample card and press Space: plays from the start; press again to stop.
- A vertical line follows the playback on the waveform, and playback stops by itself at the
  end. Ctrl / Shift-click only selects and makes no sound.
- The sound comes out of the default Windows playback device. You hear the sample's original
  file; the channel's pitch, trim, reverse and volume settings have no effect.
- wav and mp3 can be auditioned. Formats that the player built into Windows cannot play,
  such as flac and ogg, cannot be auditioned; clicking one explains this in the status bar.
- A very long sample plays for at most two minutes from where you clicked.
- Patterns and instruments cannot be auditioned.


4. The buttons in the window
----------------------------
Send to FL                    Sends the selected cards to the running FL.
Merge into file…              Without going through FL, writes the selection into a "new
                              copy" of another .flp; the original file is untouched.
Show file                     Shows the file behind this card in Explorer.
Drag samples as audio         When on, dragging a sample card out gives the wav itself
                              instead of a preset with the channel settings.
Auto-save FL before Patterns  When on, sending a Pattern saves and sends without asking.
                              When off, it asks every time.
On top                        Keeps this window in front, which makes dragging into FL easier.


5. Good to know
---------------
- Sending a Pattern saves the target project. Each save in FL leaves an "overwritten" backup
  in the project's Backup folder; if you are unsure, save a copy of the target project first.
- If FL has not switched to the new Pattern after sending (for example because FL was
  showing a dialog), pick the number given in the status bar yourself in the Pattern
  selector at the top of FL. While FL is on another Pattern, the rows of the new instruments
  are empty; that does not mean the notes did not arrive.
- The source project is read from the file saved on disk. After changing the source project
  in FL, save it first, then click "Refresh".
- Sending the same Pattern twice loads its instruments twice.
- Sending only samples or instruments (without a Pattern) does not save the target project.
- With several FL windows open, FL decides which one receives. Keeping only one open is
  recommended.
- Dialogs that plugins show while loading (for example Omnisphere's library notice) only
  need to be dismissed.


6. What is not carried over
---------------------------
Mixer effects and routing, automation clips, the Playlist arrangement, Layer channels, and
event automation inside Patterns.


7. Uninstalling
---------------
- Installer: find FL Transfer under "Settings → Apps → Installed apps" in Windows and click
  Uninstall, or use "Uninstall FL Transfer" in the Start menu. The uninstaller asks whether
  to delete the settings and temporary files as well.
- Portable: close the program, then delete the whole folder.
- Settings are kept in %APPDATA%\FLTransfer and temporary files in %TEMP%\FLTransfer; both
  can be deleted by hand.
- Upgrading: run the new installer and install to the same place; the settings are kept.


8. Questions and answers
------------------------
Q: Running the installer or the exe, Windows says "Windows protected your PC", or the
   antivirus blocks it?
A: The program has no digital signature. Click "More info → Run anyway", or add it to the
   antivirus's trusted list.

Q: It says "FL Studio is not running"?
A: Open FL and the target project first, then send.

Q: It says "The project open in FL has never been saved"?
A: Press Ctrl+S in FL and save the target project once under a name.

Q: While saving, FL shows "Invalid data" (There are invalid notes in this project…)?
A: The target project contains notes that point to channels which do not exist. Click Yes to
   let FL delete them; the tool then carries on sending.

Q: An instrument that was sent makes no sound, or FL says the plugin cannot be found?
A: That plugin is not installed on this computer, or it is a different version.

Q: Auditioning makes no sound?
A: First check that the default Windows playback device is the one you are listening to (the
   speaker icon in the taskbar).
   If there is no sound while FL Studio is open but there is once FL is closed, FL's audio
   driver (ASIO) has taken the sound card for itself: try switching to FL Studio ASIO in
   FL's audio settings.

Q: The program fails or does not respond?
A: Errors are logged in %TEMP%\FLTransfer\error.log; send that file to the author.
   The tool's temporary files are all in %TEMP%\FLTransfer as well and can be deleted at
   any time.

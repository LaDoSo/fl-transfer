FL Transfer 1.2.1 使用说明
==========================

把一个 FL Studio 工程里的采样、乐器和 Pattern，搬到另一个正在 FL 里打开的工程里。
Pattern 会带着它用到的全部音源一起过去，音源内部的参数保持原样。
采样可以先在窗口里试听，再决定搬哪一个。


一、需要什么
------------
- Windows 10 / 11，64 位。不需要安装 Python 或其它东西。
- FL Studio。本工具在 FL Studio 2025（25.2.5）上测试过，其它版本没有测试过。
- 来源工程用到的插件（Serum、Keyscape 等）要装在这台电脑上，否则 FL 加载不出音源。


二、怎么用
----------
1. 启动 FL Transfer：
   - 安装版：运行 “FL-Transfer-Setup-1.2.1.exe” 装好后，从开始菜单或桌面的
     “FL Transfer” 打开。安装只对当前用户生效，不需要管理员权限。
   - 免安装版：解压整个压缩包到任意位置，双击里面的 “FL Transfer.exe”。
     （整个文件夹要放在一起，不要只把 exe 单独拿出来。）
2. 在 FL Studio 里打开“目标工程”，也就是要把东西加进去的那个。目标工程必须保存过（有文件名）。
   FL Studio 可以装在任意盘。发送时会优先识别当前运行的 FL。如果弹出选择窗口，
   到 FL Studio 的安装文件夹里选 FL64.exe 或 FL.exe，工具会记住这个位置。
3. 在 FL Transfer 窗口顶部的“来源工程”里，选要从中取东西的 .flp
   （下拉列表是 FL 最近打开过的工程；也可以点“浏览…”，或把 .flp 拖进窗口）。
   想找某个采样，在“采样搜索”里输入文件名或通道名的一部分。右侧显示匹配数和采样总数。
   在搜索框里按 Esc 或点“清除”可显示全部采样。被筛掉的采样会自动取消选中。
4. 窗口里上半部分是 Pattern，下半部分是采样和乐器。把卡片搬进 FL 有三种方式，效果一样：
   - 把卡片拖到 FL 窗口上松开；
   - 双击卡片（采样卡片要双击标题栏；在波形上点击是试听，见第三节）；
   - 单击选中（Ctrl / Shift 可多选），再点“发送到 FL”。
5. 发 Pattern 时：
   - 工具会先让 FL 保存一次目标工程（等于替你按 Ctrl+S）。第一次会问你是否同意。
     这一步省不掉：音符要写明落在第几个通道上，而这个数只能从保存后的文件里读。
   - 然后 FL 加载音源，新通道出现在通道机架最下面。
   - 加载完后 FL 会自动切到新建的那个 Pattern，音符就在新音源那一行里。
   - 窗口底部的状态栏会写明新 Pattern 是第几号。


三、试听采样
------------
- 点采样卡片的波形：从点的那个位置开始播放。正在播放时点别的位置，就跳到那里接着放。
- 点采样卡片标题栏左端的小三角：从头播放；再点一下停止。
- 选中一张采样卡片后按空格：从头播放；再按一下停止。
- 播放时波形上有一条竖线跟着走，播完自动停。按住 Ctrl / Shift 点击只是多选，不出声。
- 声音从 Windows 的默认播放设备出来。听到的是采样的原始文件，
  通道里的音高、裁剪、反向、音量这些设置不起作用。
- wav 和 mp3 可以试听。flac、ogg 等 Windows 自带播放器放不了的格式不能试听，点了会在状态栏说明。
- 很长的采样，从点的位置起一次最多连续放两分钟。
- Pattern 和乐器不能试听。


四、窗口里的按钮
----------------
发送到 FL                    把选中的卡片发给正在运行的 FL。
合并到工程文件…              不通过 FL，直接把选中的内容写进另一个 .flp 的“新副本”，原文件不动。
定位文件                      在资源管理器里显示这张卡片对应的文件。
采样拖出为音频文件            打开后，采样卡片拖出去的是 wav 本身，而不是带通道设置的预设。
发 Pattern 前自动保存 FL 工程  打开后发 Pattern 不再询问，直接保存再发。关着时每次都问。
置顶                          让本窗口保持在最前面，方便往 FL 里拖。


五、要知道的事
--------------
- 发 Pattern 会保存目标工程。FL 每次保存都会在工程的 Backup 文件夹留一份 overwritten 备份；
  不放心的话先把目标工程另存一份。
- 发完 Pattern 后如果 FL 没有切到新 Pattern（比如当时 FL 弹着提示框），请在 FL 顶部的
  Pattern 选择器里手动选状态栏写的那一号。停在别的 Pattern 上时，新音源那一行是空的，
  这不代表音符没过去。
- 来源工程读的是磁盘上保存的文件。在 FL 里改了来源工程，要先保存，再点“刷新”。
- 同一个 Pattern 发两次，音源会加载两份。
- 只发采样或乐器（不带 Pattern）不会保存目标工程。
- 同时开着多个 FL 时，由哪一个接收是 FL 决定的。建议只开一个。
- 插件加载时自己弹出的提示框（比如 Omnisphere 的素材库提示），点掉即可。


六、不会带过去的东西
--------------------
混音器上的效果器和路由、自动化剪辑、播放列表里的编排、Layer 通道、Pattern 里的事件自动化。


七、卸载
--------
- 安装版：在 Windows 的“设置 → 应用 → 已安装的应用”里找到 FL Transfer 点卸载，
  或用开始菜单里的“卸载 FL Transfer”。卸载时会问是否一并删除设置和临时文件。
- 免安装版：先关掉程序，直接删除整个文件夹。
- 设置保存在 %APPDATA%\FLTransfer，临时文件在 %TEMP%\FLTransfer，都可以手动删除。
- 升级：直接运行新版安装程序，装到原来的位置即可，设置会保留。


八、常见问题
------------
问：运行安装程序或双击 exe 时 Windows 提示“已保护你的电脑”或杀毒软件拦截？
答：程序没有数字签名。点“更多信息 → 仍要运行”，或在杀毒软件里加入信任。

问：提示“FL Studio 没有在运行”？
答：先打开 FL 和目标工程，再发送。

问：提示“FL 里开着的工程还没有保存过”？
答：在 FL 里按 Ctrl+S 给目标工程起个名字保存一次。

问：保存时 FL 弹出 Invalid data（There are invalid notes in this project…）？
答：目标工程里有指向不存在通道的音符。点“是”让 FL 删掉它们，工具会接着发送。

问：发过去的音源没有声音或显示找不到插件？
答：这台电脑上没装那个插件，或版本不同。

问：试听没有声音？
答：先确认 Windows 的默认播放设备是你正在听的那个（任务栏的小喇叭）。
    如果 FL Studio 开着时没有声音、关掉 FL 就有，是 FL 的声卡驱动（ASIO）独占了声卡：
    可以试试在 FL 的音频设置里换用 FL Studio ASIO。

问：程序出错或没反应？
答：错误记录在 %TEMP%\FLTransfer\error.log，把这个文件发给作者。
    工具的临时文件也都在 %TEMP%\FLTransfer 里，可以随时删除。
